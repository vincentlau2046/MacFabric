# MacFabric 全页面 UI 规范 v2

> 2026-11-16 · 依据已批准的统一资料＋分类表格＋详情路线制定。
> 配套：[产品定义](2026-11-16-product-definition-v2.md)。本规范约束现有及新增页面；视觉样稿仍需确认后才实施界面代码。

## 1. 设计目标

Mac 原生的模型工作台：型号看得清，能力可比较，状态可信，动作可预测。视觉重点是模型名称与稳定列线，而不是包编号、彩色标签和卡片边框。沿用织物蓝、SF 字体与既有侧栏术语，不新增一套装饰风格。

- 多对象比较使用表格；解释放选中项详情；配置用对齐表单；总览允许少量聚合面板。
- 表头和数据使用同一列定义，禁止独立 HStack 任意分配宽度。
- 工程身份不作用户标题；未知不编造；颜色永远不是唯一信息。

## 2. 令牌

| 类别 | 规范 |
|---|---|
| 浅色 | desk #F5F5F8；panel #FFFFFF；accent #3D5CE5 |
| 深色 | desk #101014；panel #17171C；chrome #1E1E25；accent #5F7DFF |
| 正文/次级/分隔 | 原生 primary/secondary/separator 语义色；不可把浅色 ink 写死到所有主题 |
| 状态 | 系统成功/警告/错误色＋中文文字＋可识别图标 |
| 字体 | SF Pro / PingFang SC；标题14 semibold、正文13、次级11–12；ID/路径用 SF Mono；数值 monospacedDigit |
| 间距 | 4/8/12/16/24pt，内容边距16pt，表头/行横向 inset12pt |
| 控件 | 原生 regular/small；同组同尺寸；图标按钮可点击区至少28×28pt，有可访问名称 |
| 表格 | 表头32pt，标准行56pt；大字体/辅助设置允许增高；不锁高裁字 |
| 圆角 | 主表面10pt、详情面板14pt、小控件7pt；不为每行加一张圆角卡片 |
| 动效 | 0.15/0.25s，仅表达用户动作/状态；Reduce Motion 关闭非必要动画 |

资源显示统一 MiB/GiB（1024换算），最多一位小数；右对齐。未知“未知”，估算“约 2.1 GiB”，实测标明峰值/当前值，不混淆下载/磁盘/内存。路径、错误原文可选中复制。

## 3. 共享页面骨架与响应布局

页面标题＋一句必要说明 → 工具栏（搜索/筛选/主动作）→ 表格或表单 → 选中项详情。页面内同一时刻最多一个强调色主动作，不让每行按钮争抢视觉。

列规则以**内容区可用宽度** W 计算，不含侧栏：
- W≥1100：完整列；详情可并排320pt，但要在扣除详情后重新计算表格宽度。
- 820≤W<1100：能力列移至详情，资源压缩为一项；详情以 sheet/抽屉打开，不挤主表。
- W<820：保留模型名/类型/状态/动作，资源与标签移详情；不堆多行徽章。主窗口最小宽度900pt（含侧栏），仍须测试详情/分屏造成的窄内容区。
- 表格模型名列最小220pt、可伸展；类型96pt、状态104pt、资源104pt、动作100pt；列间隙12pt。能力列最小140pt，仅空间充足时出现。
- 长标题单行尾截＋悬停全文＋详情完整名称可复制。辅助字体增大时可改两行，不能挤掉动作或焦点。
- 列不能满足时先按规则移除次列，不产生整窗横向滚动；局部技术日志/代码区可横向滚动。

行身份 = instance_id；目录行身份 = pack_id＋variant；排序不改变动作目标。选择行在轻底色高亮中体现，表格 header 与行逐列对齐；详情打开后刷新保留选择，目标消失时关闭并说明。

## 4. 本地推理

```text
本地推理                      [搜索模型] [类型] [运行状态]
模型名称                   类型       能力            运行状态    内存基线     操作
BGE-M3                     文本嵌入   多语言/语义检索  未加载      约 2.1 GiB  加载  ⋯
Qwen3-4B-Instruct-2507      文本生成   中文/对话        可用        约 4.7 GiB  测试  ⋯
```

数字与标签仅为版式示例，交付时取后端资料和证据。

详情包含：官方型号/变体/能力证据、公开调用 ID、实际加载策略与空闲回收、自动启动、基线/实测、安装路径（复制/Finder）、引擎版本/端口、包与内部实例 ID。

- 主行不放 pack-ID 徽章、端口、自动启动开关、长装载文案。
- 运行词典：未加载 / 加载中 / 可用 / 已睡眠 / 异常。独立于包的未安装/安装中/已安装/失败。
- 动作词典：“加载”“唤醒”“测试”；“从内存卸载”≠“卸载能力包”。删除部署资产的弹窗列出包、路径、引用影响，必须确认。
- 类型决定试用：聊天、图片问答、嵌入比较、查询＋文档排序；其余未交付类型不展示可用假入口。

## 5. 能力包

类型筛选＋“全部”分组表头＋分类表格，取代卡墙。

主列：模型名称｜能力｜变体｜下载/磁盘｜兼容性｜验证｜安装状态｜操作。使用共享断点；中窄宽度下载/磁盘、变体、能力依次入详情，兼容性/验证合成两行的“准入”列但数据维度不合并。

- 可切“适配本机/全部”，受策略限制的模型可查看原因，不直接隐藏、不自动改设置。
- 状态：未安装 / 安装中（真实阶段）/ 已安装 / 失败 / 卸载中；进度总量未知用不定进度，不伪造百分比。
- 兼容性：可安装 / 需适配 / 暂不支持；额外给资源/策略阻断原因。
- 验证：待验证 / 已验证 / 验证失败；与来源官方精选/用户添加分开。
- 同型号多变体在详情选择；预设路径和真实路径均可见。资源、许可、摘要、源和证据可追溯。
- “添加模型链接”是页面主动作；输入链接后识别资料，必要时要求确认，不让用户填写 pack slug。
- 失败包含阶段＋原因＋可行下一步；支持才显示取消/重试；危险阶段不可取消时明确说明。

## 6. 模型服务

顶部固定接入信息：当前 profile 的 Base URL＋真实推理鉴权状态＋App key 状态。未知/失联不能写“未启用”。

表格：模型名称｜类型｜来源（本地/云端/模型池）｜可用状态｜接入。**本地与云端模型同页按类型统一分类呈现**：类型筛选同时作用于两侧，同类型号在同一列线内比较；云端行标注服务商并原样保留上游调用 ID，不套本地命名正则，云端配置由网关持有密钥。未部署的目录项不混入本地可调用清单。

模型池是**独立的服务概念**：同类能力聚合并统一路由的集中配置（如 `fabric-fast` 聚合轻量对话候选），调整池规则（候选、顺序、回退）一次即对调用它的多个 Agent 同时生效。池在表格中以逻辑 ID 分组呈现，不冒充单个模型；接入详情给出池 ID 与端点。

- cURL 引用 `$MACFABRIC_API_KEY`，JSON 使用 `YOUR_GATEWAY_API_KEY`，不复制真实 key。
- BGE-M3 默认嵌入示例，不提供聊天/Anthropic 配置；VL 示例有图像输入；云端模型按其实际协议能力生成示例，没有端点适配就不生成伪有效配置。
- 未加载但可按需唤醒显示“按需可用”；未部署目录项不混入本地可调用清单。
- 硬切迁移通知列旧→新 ID 与客户端需更新项，不能因界面只显示真名而隐藏破坏性改动。

## 7. 其他页面责任矩阵

| 页面 | 信息组织与必须一致项 |
|---|---|
| 总览 | 少量聚合面板＋运行摘要；同一内存口径、真名称；不重复设置保留内存 |
| 菜单栏 | 状态灯附文字/可访问说明，简洁运行列表、即时停止/睡眠；不追加未裁决快速聊天 |
| 模型池 | 同类能力聚合的独立路由服务：候选/顺序/回退集中配置，一处调整对多 Agent 生效；名称＋本地/云来源可见；调用 ID 在接入详情；未知候选保留并标异常，不静默删除 |
| 监控台 | 表格对齐时间/模型/状态/延迟/token；未测显示未知；历史保留原始 ID；同名实例不合并；睡眠不渲染故障 |
| 云端接入 | 服务商和模型分层，发现/启用/可路由分开；上游 ID 详情原样保留；key 遮蔽，不与网关 key 混称 |
| 设置 | 分组表单，统一 label/control/help 三段；草稿/未保存/保存中/成功/失败明确；策略唯一编辑入口 |
| 首启 | 复用设置组件/验证口径；不创建第二套鉴权、资源默认值；错误不吞、可重试 |

加载策略、资源与状态均读取统一 DTO，不在视图内另写 8192、30min 或模板白名单。未知类型绝不默认“对话”。

## 8. 错误、空态、键盘与可访问性

- 空态说明如何开始，例如“还没有已安装的本地模型”＋“查看能力包”。搜索无匹配与未安装分开。
- 页面首次加载、刷新失败、旧数据 stale 各自表达；网络失败保留旧数据但标时间，不能变成空清单。
- 401：“网关拒绝了调用密钥，请检查或重新录入”；403：“此密钥无权调用该模型”。只有后端明确提供撤销/过期原因才使用相应文案。不得提示用户重新装模型来修鉴权。
- 所有按钮/切换/菜单可键盘到达，焦点可见；按 Return 打开详情、Esc 关闭弹层；破坏操作不得绑定无确认的默认 Return。
- VoiceOver 读出模型完整名称、类型、运行态、动作；图标必须有 label，长标题截断不截可访问文本。
- 明暗主题、Increase Contrast、Reduce Motion 与字体增大都验收。原生控件优先，不私绘难以访问的开关。

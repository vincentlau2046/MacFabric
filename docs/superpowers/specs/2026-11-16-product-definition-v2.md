## 1. 裁决与权威关系

| 编号 | 已裁决 | 边界 |
|---|---|---|
| R1 | 统一资料＋分类表格＋详情面板，不再局部补卡片 | 现有界面、现有安装模型同样适用 |
| R2 | 模型真名作标题；内部 pack ID 退至详情；**调用 ID 同步硬切** | 不保留旧 ID 路由别名；不等于现在执行生产迁移 |

| R6 | 强隔离、原生 GUI、语义 E2E、双端发布产物一致为硬门禁 | 不以 API 200、编译成功或浏览器截图代替 |

本文件、全页面规范及 PLAN 的本次补充替代旧审核稿中“保留既有调用 ID”的建议。旧能力包文档仍约束事务、资产和来源；冲突时以本次明确裁决为准。以下字段名、迁移步骤、布局尺寸属于执行设计选择，不冒充用户逐字裁决；计划审核时可修订。

备选曾比较：A 局部美化不能消除资料分裂；B 统一产品资料＋表格/详情是已选路线；C 全重写破坏现有原生技术与回归资产，排除。

## 2. 产品对象与能力边界

- **能力包**：全部精选/用户添加能力的目录和部署管理；按类型比较模型、变体、资源、兼容性与验证证据。
- **本地推理**：仅已部署能力的运行管理。安装成功、已加载、当前可调用是不同事实。
- **模型服务**：本地与云端全部可调用模型按类型统一呈现的接入出口；云端模型原样保留上游 ID、按实际协议能力生成示例；只为实际支持的端点生成示例。
- **模型池**：独立的服务概念——同类能力聚合并统一路由的集中配置，调整池规则（候选/顺序/回退）一次即对调用它的多个 Agent 生效；`fabric-*` 逻辑 ID 保持，不因 UI 改版更名；不把嵌入/重排塞进聊天池。
- **监控台**：运行/请求证据。显示名可更新，历史原始 ID 不改写、不按同名合并实例。
- 云端接入、设置、首启、菜单栏遵循同一资料与状态词典。

统一的是安装、注册、资源、调用、验证、卸载合同，不是把所有类型塞进 llama.cpp 文本生成模板。新运行时仍需独立适配与审核。保持 SwiftUI＋AppKit，无 WebView，无全 Swift 网关重写。

## 3. F1：统一模型资料与命名

### 3.1 身份字典

| 字段 | 语义 | 约束 |
|---|---|---|
| `instance_id` | 内部生命周期身份 | 第一版映射现有 `ModelConfig.name`，保持状态/睡眠键和文件名稳定 |
| `display_name` | 用户看到的官方型号 | 保留大小写、4B/Instruct/2507 等型号信息；不得拼接包前缀与包版本 |
| `api_model_id` | 公开调用名 | 显式注册，所有公开端点唯一；禁止内部名回退 |
| `pack_id` / `pack_version` | 部署来源 | 技术详情，可复制，不作主行标题 |
| `variant` | 量化/格式/模型修订 | 结构化资料，不能与包版本混为一谈 |

名称不能靠前端删除 `pack-` 猜测。官方目录、用户注册资料和运行配置共享字段；旧资料只能从可靠元数据补齐。未知显示“资料待补全”，未知类型显示“未知类型”，不得默认归为对话。

公开 ID 使用小写 ASCII 字母、数字和连字符，正则 `^[a-z0-9]+(?:-[a-z0-9]+)*$`，最长 96 字符；本地注册禁止 `pack-`、`fabric-`、`cloud-` 保留前缀。默认变体采用型号 ID（如 `bge-m3`）；额外并存变体以显式量化/变体后缀区分（如 `bge-m3-q8-0`），已注册 ID 不因另装一个变体自动更名。冲突、同名异类型、多实例不可静默覆盖，须在预览中明确选择新 ID；显示名允许重复，操作始终按实例绑定。云端原始 ID 不做此正则改造，跨命名空间碰撞仍须检测并拒绝有歧义的公开注册。

### 3.2 统一资料最低合同

后端产品资料字段：`instance_id`、`display_name`、`api_model_id`、`primary_type`、`publisher`、`family`、`variant`、`capabilities`、`resources`、`runtime_support`、`verification`、`source`、`managed_by_pack`。能力标签包含 `id`、`label`、`verification`、`evidence_ref`，每行最多两个，其余进详情。

- `primary_type`：llm / vl / embedding / rerank / asr / tts / ocr / aigc；图生图和文生图是 aigc 的独立能力。
- `resources`：参数量允许 0.6/1.7 等非整数；下载、磁盘、内存使用 MiB，UI 统一换算 GiB；数值可空，附 estimated/measured/source，未知不填 0。
- 分开记录当前配置上下文和理论上限；BGE-M3 当前仅可宣传有证据的 dense 能力，不能扩大为 sparse/多向量。
- `runtime_support`：supported / adaptation_required / unsupported；另附当前资源/策略准入结果 `eligible` 与原因。
- `verification`：pending / passed / failed，附精确引擎摘要、变体摘要、测试报告与时间。更换任一绑定产物，旧证据不可继续当新产物的 passed。
- 安装态、兼容性、验证态、运行态独立。`installed` 不自动推出 `ready` 或 `passed`。

管理 `/models` 可保留内部 `name` 供生命周期操作，但新增明确产品字段；`/v1/models` 仅输出公开 ID，不泄漏内部名。已部署且支持的本地能力不因另一模型正在运行而从公开目录随机消失；按需未加载模型仍可列出，失效配置/占位包不得伪装可用。

## 4. F2：既有调用 ID 硬切与迁移

### 4.1 范围

硬切覆盖 chat、messages、embeddings、rerank、公开目录、池本地候选、密钥 model scope、接入示例、公开引擎 alias、缓存命中与错误文案。公开 resolver 不再回退 `ModelConfig.name`；内部 `get_model(instance_id)` 留给启停、睡眠、监控与包管理。

旧 ID 集合是“迁移前确实接受的调用名”，不只是某一个 YAML 字段。退役集合 = 旧接受集合减去最终 canonical 集合；原本已规范且等于最终 ID 的 `bge-m3` 等不应被错误退役。现有两包目标：`BGE-M3 → bge-m3`，`Qwen3-4B-Instruct-2507 → qwen3-4b-instruct-2507`；其他实例必须预览实际映射，不猜资产。

保留 `fabric-*`、云服务商 ID、内部状态键、历史 request log。历史显示翻译不是路由兼容别名。客户端的外部配置无法自动发现或改写，迁移预览给出逐项更新清单。

### 4.2 执行合同

1. **只读预览**：枚举配置、已接受 ID、模型池原始配置、密钥 scope 与目录冲突，返回旧→新映射、受影响引用数量、无法映射项、版本/摘要和风险。不得泄漏 digest 或密钥。
2. **失败关闭**：无法映射、歧义、非包旧旁路、权限扩大或生产路径不符均阻止 apply；不能丢候选，也不能把 scoped key 改成 unrestricted。
3. **受保护确认**：使用现有安全管理控制台的 Host/Origin、密码会话、CSRF 机制；推理 Bearer key 不作为管理员凭证。通用 `/admin` 无 token 不能成为迁移授权。
4. **维护窗口**：显式批准后拒绝新写操作/新推理，等待在途结束（最多 180 秒；超时中止，不盲杀），重核对预览摘要/CAS，停相关引擎再改 alias。
5. **备份与日志**：配置、原始池、registry、scope 与缓存版本关联快照；私有备份权限 0700/0600。security.db 由 KeyStore 使用一致性备份，不复制不一致的 WAL 文件。记录 prepared/applied/committed/rolled_back/recovery_required 事务日志，不能宣称跨文件＋SQLite天然原子。
6. **领域内写入**：KeyStore 自身事务改 scope，保留 id/digest/expiry/revocation/policy；模型池通过原始配置与 revision-aware 接口更新，保留未知/未解析候选。禁止脚本直接写生产 DB。
7. **提交门禁**：配置、公开索引与 scope 全部更新后，清理/升代相关响应缓存，重载并验证；有合法 key 时退役 ID 必须 404，包含预置旧缓存场景；缺 key 仍按既有鉴权策略拒绝，不泄漏存在性。
8. **故障恢复**：任一步失败维持维护状态；恢复协调器依日志完成回滚或验证后提交。启动发现未完成日志先恢复，不能带半套新旧权限对外服务。回滚同时恢复代码兼容版本、配置、scope、缓存代际和 App，单独换旧 tag 不算回滚。

此合同是将来实现范围；生产 apply 与 rollback 都须迁移点报备。文档确认不自动触发生产维护。

## 5. F3：全页面 UI

所有现有页面与后续新页面使用 [UI v2](2026-11-16-ui-standard-v2.md)。共享资料、共享列宽、共享状态组件；表格负责比较，详情负责解释。设置/首启用表单，不机械把所有页面变成表格。

进入 UI 实现前，提交本地推理、能力包、模型服务三张视觉样稿，覆盖长名称与窄窗，待用户确认。样稿是评审材料，不代替原生 GUI 验收。旧设计 `design/ui-design-v0.html` 保留作词汇参考，冲突以 UI v2 为准。

## 6. F4：鉴权、接入与按能力试用

已核实生产推理鉴权启用（policy=all）；“鉴权未启用”是前端硬编码，不是用户未设置。不能把管理状态接口 200 当推理免鉴权。

- 状态模型：loading / enabled_all / enabled_pools / disabled / unavailable；保留上次成功值时标 stale 与更新时间。HTTP 非 2xx、无效 JSON、超时不可映射为 disabled。
- 推理状态、本机管理权限、App 当前持有的调用 key 三者单独表达。网关不可恢复 key 明文；只让用户录入已有 key，可选 Keychain 或仅本次会话。
- Keychain 按 profile＋gateway origin 隔离，开发和生产绝不共用；保存/删除失败、锁定或用户拒绝要可见，不能假装保存成功。不得把 key 写偏好文件、日志、示例或剪贴板。
- 所有 App 推理请求统一注入用户所选 key；管理请求不挪用该 key。401 提示检查 key，403 提示 scope/策略；撤销/过期只有后端明确给出原因时才细分，不能从同一个错误猜测。
- 复制示例使用 `$MACFABRIC_API_KEY` 或 `YOUR_GATEWAY_API_KEY` 占位符；Base URL 与 ID 按真实 profile 生成。嵌入用 `/v1/embeddings`，重排用 `/v1/rerank`，聊天/视觉才提供对应 chat/messages 示例。
- 试用按类型分派；不允许无 LLM 时回退到任意首模型。尚未交付的类型不提供假试用按钮。

广义管理面凭证硬化单独设计审查，本轮不借机更换全体管理 API 身份机制；迁移端点自身必须继承现有强保护。

## 7. F5：四类 12 型号目录

| 类型 | 显示名／目标公开 ID |
|---|---|
| 文本生成 | Qwen3-0.6B / `qwen3-0-6b`；Qwen3-1.7B / `qwen3-1-7b`；Qwen3-4B-Instruct-2507 / `qwen3-4b-instruct-2507` |
| 文本生成 | Qwen2.5-Coder-1.5B / `qwen2-5-coder-1-5b`；Qwen2.5-Coder-3B / `qwen2-5-coder-3b`；LFM2-2.6B / `lfm2-2-6b` |
| 文本嵌入 | BGE-M3 / `bge-m3`；BGE-small-zh-v1.5 / `bge-small-zh-v1-5`；Qwen3-Embedding-0.6B / `qwen3-embedding-0-6b` |
| 相关性重排 | BGE-reranker-v2-m3 / `bge-reranker-v2-m3` |
| 视觉理解 | Qwen3-VL-2B / `qwen3-vl-2b`；Qwen3-VL-4B / `qwen3-vl-4b` |

每型先选一个推荐变体。模型源继续 ModelScope；需逐条记录确切文件、转换来源、许可、SHA256、体积、配置上下文、实测内存与端点证据。表中 ID 是命名设计目标，不意味着已经安装。没有合规源、固定版本兼容或语义证据则留候选，并报告原因；不以其他型号替换凑够 12。

以 llama.cpp **b12361** 为回归基线。文本、嵌入（pooling/normalize/query 格式）、BGE 重排（输入/分数/index）、视觉（模型＋匹配 mmproj）分别实现模板。若需升级，先在完全隔离环境做兼容验证，提交确切 tag/commit、arm64 产物摘要和既有两包回归，另行冻结后使用；不能追 master。Qwen3-Reranker 不在首批，不能套 BGE 语义。

## 8. F6：用户扩展共用底座

粘贴下载链接 → 安全元数据识别 → 补缺失类型/投影/资料 → 资源预检 → 用户确认 → 下载/流式校验 → 执行隔离 → 类型语义验证 → 注册/热加载。官方、自定义、本机发现三入口必须汇入同一安装事务；不符合统一合同的旧导入入口移除或停用并说明，不继续写旁路 YAML。

- HTTPS、逐跳重定向与目标地址校验，拒绝私网/loopback/元数据地址；检查 IPv4/IPv6、DNS 重绑定、URL 内凭证、大小/超时、解包路径。安装路径受控，不执行远端脚本。
- 下载前预检磁盘与已知元数据，未知长度采用流式硬上限（沿用 32 GiB 上限）；哈希不得整文件读内存。GGUF 元信息与声明交叉验证，不以魔数或文件大小估参数量。
- 0.6/1.7B 可准确表示；未知关键资源不绕过。LLM/VL 默认 ≤4B，可在设置修改；其他类型走内存门禁。
- 引擎是独立、固定版本、可校验的托管依赖，不跨模型包软链借用；引用计数与进行中 pin 防止卸载 A 破坏 B。
- 安装事务覆盖恢复、失败清理、受控取消、并发预算、重载和卸载；不支持取消的阶段不能虚假承诺取消。完成终态要求无需重启即可调用；官方和用户链分别验。
- 不把用户模型通过试用标为“官方质量已验证”；兼容可用与来源背书分开。

## 9. F7：资源、隔离与交付

- 唯一预算 `B = RAM − reserve`；reserve 优先级：显式 `MACFABRIC_RESERVE_MB` ＞ policy `system_reserved_memory_mb` ＞ 8192 MiB。只有设置页能力包策略可编辑；覆盖时显示覆盖来源，账本只读，不重复扣 reserve。
- 新包装载默认沿用原基线：LLM/VL on_demand、idle=10min；嵌入/重排 resident。已有显式 30min/autostart/用户值保持不变并显示真实值，不借改版重置。
- 开发固定 8998、生产 8999；state/packs/registry/policy/models.d/池/云配置/日志/Keychain/引擎依赖完全独立。检查 realpath、文件 inode 和包内 runtime 链接，写目标指生产立即拒绝；复制配置不等于去除生产绝对路径。
- 正式与试加载引擎仅监听 loopback；最小环境继承、不携云端密钥；真实限制写目录/网络/文件描述符/并发，准确展示 sandbox degraded。符号探测、独立进程组、未接线 rlimit 不算强隔离。完整隔离未满足时按已有准入政策阻断，不静默降级。
- 原生最小/标准/大窗、亮暗、键盘/VoiceOver、长名称和 30+ 行验收；浏览器截图不能替代。
- 语义 E2E：正文非空且切题；图片相关；嵌入语义相似度有序；重排索引与顺序真实；同时覆盖合法/缺失/错误/撤销/超 scope key、安装免重启、失败/取消/恢复/卸载与生产零穿透。
- 网关与 App 同一已验证 release manifest（commit、schema、迁移版本、双端摘要）安装；生产不从源码构建、依赖解析或本地 build 直拷。不把仅源码 tag 当已验证二进制交付。安装前校验，成对回滚演练后再晋升。

## 10. 后续能力与验收边界

OCR→ASR→TTS→图像生成为蓝图顺序，不是本轮全部实现承诺。macOS Vision helper、whisper.cpp、系统 say/Kokoro ONNX、mflux 各交源/许可/依赖/接口方案再审。Whisper 在源条件解决或明确复议前继续退出目录；Gemma 许可证复核前不进任何交付批次；不得将 Kokoro ONNX 暗换 MLX。

可分阶段验收，但任何未通过项明确保留未完成。per-attempt TTFT 单独待立项，不搭本次改版顺带改。验收证据不写密钥、digest、私有云配置；私有迁移快照不入仓库。
